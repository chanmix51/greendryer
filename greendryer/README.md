# Green dryer

The aim of this project is to turn an old fridge into a plant dryer. To achieve so, a microcontroller ensures the Vapor Pression Deficit (VPD) stays in a narrow band between 0.6kPa and 0.8kPa. The actuators are 

 * the fridge itself, the ESP32 becoming its thermostat. When active, the temperature goes down, HR goes up so the VPD goes down. It ensures the temperature is low enough to preserve terpenes.
 * a cheap dehumidifier using a peltier module that removes moisture from the air placed inside the cabinet. When active, the HR goes down, temperature goes up so the VPD goes up. It ensures the HR remains low enough to prevent mould.

The microcontroller is an ESP32 based board with I2C bus and at least 2 free GPIO pins. Using a SHT31 temperature and humidity probe placed inside the cabinet, it computes the VPD and uses a 2 relays board to switch either the fridge using the thermostat and/or the dehumidifier through its main power. All informations are displayed on a 128x64 OLED SSD1306 Display.

The constraints are the following:
 * keep the humidity rate under 70% at all time.
 * let the fridge compressor rest 10 minutes between 2 runs.
 * keep the temperature under 19°C.
 * keep the VPD in the 0.6kPa - 0.8kPa range.
 * robust against bad probe measures (at least 5 samples to take a decision).
 * turn everything off in case of an actuator timeout (20 min for the fridge, 30 min for the dehumidifier).
 * turn everything off if the probe fails to send 5 samples in a row and restore state after probe is fixed.
 

## Required materials

- An old fridge, used as the closed cabinet. Its thermostat is the cooling actuator.
- A Peltier dehumidifier inside the cabinet.
- A fan if the fridge hasn't got one.
- An ESP32.
- An SHT31 temperature and humidity sensor, I2C address `0x44`.
- An SSD1306 128×64 OLED, I2C address `0x3C`, on the same bus.
- A relay board with active-low inputs. The firmware drives four outputs and holds the two unused ones off:
  - GPIO14 — fridge thermostat
  - GPIO27 — dehumidifier main power
  - GPIO26 and GPIO25 — unused, held off
- I2C wiring: SDA on GPIO21, SCL on GPIO22.

## Contributing

Contributions are welcome as tested merge requests. From `greendryer/`, run `cargo test` and include tests for the behavior you change. The mode decision is a pure function of the samples and the current state, so those tests run on the host and do not need the chip.
