# Green dryer

Firmware that turns an old fridge into a plant dryer.

The cabinet is a closed, insulated fridge in a room at about 18°C or below. Plants inside release moisture into the air. An ESP32 switches the fridge compressor and a Peltier dehumidifier so the air stays in a narrow band: vapor-pressure deficit between 0.6 kPa and 0.8 kPa, and relative humidity that does not remain above 70%. The only actuators are that compressor and that dehumidifier.

This is for you if you already have a fridge in a cool room, you want to dry plants by holding that climate, and you can switch the compressor and a Peltier unit with relays. The controller is Rust firmware for an ESP32 (`no_std`, Embassy) in [`greendryer/`](greendryer/). It reads one SHT31 probe about once a second and shows the current mode on an SSD1306 display.

## Required materials

- An old fridge, used as the closed cabinet, in a room at about 18°C or lower. Its compressor is the cooling actuator.
- A Peltier dehumidifier inside the cabinet.
- An ESP32.
- An SHT31 temperature and humidity sensor, I2C address `0x44`.
- An SSD1306 128×64 OLED, I2C address `0x3C`, on the same bus.
- A relay board with active-low inputs. The firmware drives four outputs and holds the two unused ones off:
  - GPIO14 — fridge compressor
  - GPIO27 — dehumidifier
  - GPIO26 and GPIO25 — unused, held off
- I2C wiring: SDA on GPIO21, SCL on GPIO22.
